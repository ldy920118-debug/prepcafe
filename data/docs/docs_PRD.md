# 제품 요구사항 문서 초안

## 사용 목적

매장 운영자가 판매·비용·재고 기록을 관리하고, 메뉴별 수익성과 기간별 실제 손익, 재료 잔량을 확인하는 프로그램입니다.

수업 중에는 **판매·비용 기록 입력 → 메뉴 수익성 확인 → 기간 손익과 재료 잔량 확인** 흐름을 우선 구현합니다. 발주 참고와 전망 등은 합의된 확장 범위로 분리했습니다.

## 자료의 종류·기간·단위·중복 주의사항

**자료에서 확인한 내용**

- 매장명은 프렙 카페이며, 자료는 가상 매장 샘플입니다. 엑셀에는 데이터 안내 시트와 공급사 3건, 재료 11건, 메뉴 8건, 레시피 22건, 재료 가격 이력 33건, 영업 달력 457건, 판매 6,112건, 초기 재고 11건, 재고 기록 1,515건, 월 비용 계획 120건, 비용 기록 3,560건, 자료 정보 10건이 있습니다. JSON은 같은 기록을 담고 있습니다.
- 실제 기록 기간은 **2025-07-01~2026-09-18**입니다. 달력은 2026-09-30까지 있으나, 이후 날짜는 미마감 상태입니다.
- 금액은 원화·부가세 제외이며, 재료 단위는 g·ml·개입니다. 구매 용량 전체 가격과 메뉴 1개당 레시피 사용량은 구분해야 합니다.
- 판매 자료는 주문 건별이 아니라 일자·메뉴·채널별 집계입니다. 레시피에는 적용 채널과 버전이 있고, 판매 기록에도 당시 레시피 버전이 있습니다.

**중복·해석 주의사항**

- 엑셀과 JSON은 동일 자료이므로 초기 데이터로는 한 형식만 사용해야 합니다. 둘 다 불러오면 기록이 중복될 수 있습니다.
- 월 비용 계획과 날짜별 비용 기록은 같은 비용을 월 단위와 일 단위로 담고 있습니다. 실제 손익에서 둘을 별도 지출로 합산하면 중복될 수 있습니다.
- 빈칸과 0은 다른 뜻입니다. 재고 증감에서 입고는 양수, 폐기는 음수이며, 실사 조정에는 실제로 센 수량이 기록됩니다.
- 연간 조회에는 일부 기간만 들어갈 수 있습니다. 미마감 날짜를 판매 0으로 간주해서는 안 됩니다.
- 파일의 과거 원가·수수료·비용 배분 결과는 미래 기록의 계산 정책을 정해주지 않습니다.

## 사용자와 사용 순서

주 사용자는 매장 기록을 관리하는 운영자로 제안합니다. 계정 수나 여러 사용자의 데이터 공유 방식은 미정입니다.

1. 첨부 샘플 기록을 한 형식으로 미리 채운 상태에서 시작합니다.
2. 판매와 비용 기록을 입력하거나 수정·삭제합니다.
3. 메뉴별 수익성을 확인하고, 일·주·월 단위의 실제 손익을 봅니다.
4. 재료 입고·폐기·실사 수량을 기록하고, 판매에 따른 재료 잔량을 확인합니다.

## 필수 기능

**수업 중 MVP**

- 첨부 샘플 데이터를 중복 없이 한 번 채워서 시작합니다.
- 판매 기록과 비용 기록을 직접 입력·수정·삭제합니다.
- 일·주·월 단위 실제 실적과 손익을 조회합니다.
- 메뉴 수익성은 메뉴에 직접 연결되는 비용 기준으로 봅니다. 임차료·인건비 등 공통 비용은 메뉴별로 나누지 않고 전체 기간 손익에서 봅니다.
- 재료 입고·폐기·실사 수량을 기록하고 잔량을 확인합니다.
- MVP 범위 제안으로, 판매 수량을 해당 메뉴의 레시피에 연결해 재료 사용량을 반영합니다.
- 기록은 다시 열어도 유지되어야 하며, 기본 입력 검증과 오류 안내를 제공합니다.

**수업 후 확장**

- 분기·반기·연간 조회
- 예상 손익 전망
- 엑셀 양식 내려받기와 엑셀 기록 가져오기
- 데이터 백업과 복원
- 부족 재료와 필요한 발주 참고량

예상 손익과 레시피 기준 재고 반영은 앞선 대화에서 추천안으로 제안했으며, 이 초안의 최종 범위 확인에 포함합니다.

## 제외 기능

이번 범위에는 POS·결제·회계 서비스 연동, 공급사로 발주를 자동 전송하는 기능, 여러 매장 관리, 세무 신고 기능을 넣지 않습니다. 필요 여부는 이후 별도로 검토할 수 있습니다.

## 완료 기준

- 샘플 데이터로 시작해 판매·비용 기록을 입력, 수정, 삭제할 수 있고 변경 결과가 저장됩니다.
- 앱을 다시 열어도 기록과 조회 결과가 유지됩니다.
- 메뉴 수익성과 일·주·월 실제 손익이 합의된 기준에 맞게 계산되고, 대표 사례를 손으로 확인한 결과와 일치합니다.
- 월 비용 계획과 날짜별 비용 기록이 손익에서 중복 반영되지 않습니다.
- 재료 잔량이 판매에 적용된 채널·레시피 버전과 입고·폐기·실사 기록에 맞게 반영됩니다.
- 날짜, 필수값, 메뉴·재료 참조 등 잘못된 입력을 검증하고 사용자가 고칠 수 있도록 오류를 안내합니다. 빈칸과 0도 서로 구분해 유지합니다.
- 사용자가 판매 입력부터 메뉴 수익성, 기간 손익, 재료 잔량 확인까지 한 흐름으로 완료할 수 있습니다.

## 미정 사항

- 메뉴 수익성의 세부 계산 기준과 새 판매 기록에 적용할 원가 기준
- 예상 손익을 만들 때 사용할 전망 기준과 월 비용 계획의 역할
- 주·분기·반기·연간 기간 경계 및 매장이 쓰는 회계 기간
- 재고 실사와 레시피 변경이 이전·이후 판매에 적용되는 기준
- 메뉴·재료·레시피 같은 기준 정보를 사용자가 추가·수정할 수 있어야 하는지
- 엑셀을 반복 가져올 때의 중복 처리, 백업 복원 시 기존 기록과의 충돌 처리
- 사용자 수와 기기 간 기록 공유 여부
